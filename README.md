# BillDrama

BillDrama is a smart, lightweight trip expense splitter. It helps groups of friends calculate fair shares and works out a simple settlement plan showing exactly who owes whom—with zero awkward money drama.

Everything runs entirely in your browser: no accounts, no sign-ups, and no backend database.

## Features

- **Simple 5-Minute Flow**: Add your squad, log who paid for what, and get instant results.
- **Smart Debt Settlement**: Minimizes the number of transfers needed to settle all debts with no circular payments.
- **Multi-Currency Support**: Switch easily between INR (₹), USD ($), EUR (€), GBP (£), and JPY (¥).
- **Fun Trip Awards**: Highlights group superlatives like the "Trip MVP" and "Budget Legend".
- **Easy Sharing**: Copy a clean summary for WhatsApp/group chats or export a PDF report.
- **100% Private**: Your data is saved locally in your browser and never leaves your device.

## Getting Started Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (v20 or newer)
- npm

### Installation & Setup

1. Clone or download this repository and open the directory:
   ```bash
   cd BillDrama
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
